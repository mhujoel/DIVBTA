# Evaluating the integrity of clinical trials in Cochrane reviews

Data, code, and documentation for a project that evaluates the integrity of randomized clinical trials included in a sample of Cochrane reviews.

The work includes a published case study of diabetes trials, a case study of the Boldt trial, and supporting simulations.

## Related publications

- Hujoel PP, Hujoel MLA. Unusual outcome variances as a method to identify potentially problematic clinical trials. *PLOS ONE*. 2026. https://doi.org/10.1371/journal.pone.0346238
- *Hiding in Plain Sight: Within-Subject Correlations as Tools to Assess Data Integrity* (manuscript submitted).
